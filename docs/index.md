# geocrime-stl

Welcome to the official documentation and landing page for **geocrime-stl**, a specialized Python package designed for geospatial crime analysis in the St. Louis area.

## Overview

`geocrime-stl` provides streamlined tools for spatial data processing, hotspot analysis, and visualization tailored to urban crime data workflows.

## Key Features

* **Spatial Analysis:** Built-in utilities for handling geospatial crime layers.
* **Visualization:** Seamless integration with interactive mapping tools.
* **Reproducible Workflows:** Designed for open-science geospatial research and reporting.
